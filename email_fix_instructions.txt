ATTENDRIX EMAIL SENDING FIX
================================

CURRENT ISSUE:
- "Unable to send reset link. Please try again later"
- SMTP credentials not configured properly
- Email sending failing with authentication error

SOLUTION:
1. Configure Gmail 2-Step Verification
2. Generate App Password (16 characters)
3. Update backend configuration
4. Test email sending

STEP-BY-STEP INSTRUCTIONS:

1. ENABLE 2-STEP VERIFICATION:
   Go to: https://myaccount.google.com/security
   Enable "2-Step Verification"
   Follow the setup process

2. GENERATE APP PASSWORD:
   Go to: https://myaccount.google.com/apppasswords
   Select app: "Mail"
   Select device: "Other (Custom name)"
   Enter: "Attendrix"
   Click "Generate"
   Copy the 16-character password (NO SPACES)

3. UPDATE BACKEND CONFIGURATION:
   Open: login_backend_fixed_final.py
   Find lines 24-25:
   SMTP_EMAIL = "your-gmail@gmail.com"
   SMTP_PASSWORD = "your-app-password-here"
   
   Replace with your actual credentials:
   SMTP_EMAIL = "your-actual-gmail@gmail.com"
   SMTP_PASSWORD = "the-16-character-app-password"

4. EXAMPLE CONFIGURATION:
   SMTP_EMAIL = "john.doe@gmail.com"
   SMTP_PASSWORD = "abcdefghijklmnop"  # 16 chars, no spaces

5. TEST CONFIGURATION:
   Run: python setup_email_guide.py
   Choose option 2 to test
   Verify test email is received

6. RESTART BACKEND:
   python login_backend_fixed_final.py
   Test forgot password functionality

IMPORTANT NOTES:
- Use App Password, NOT your regular Gmail password
- App Password must be exactly 16 characters
- Remove all spaces from the App Password
- Ensure 2-Step Verification is enabled

TROUBLESHOOTING:
- "Authentication failed" -> Wrong App Password
- "Connection timeout" -> Network/SMTP issues
- "No email received" -> Check spam folder
- "SSL error" -> TLS not enabled
