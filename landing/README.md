## Customization

### **Colors**
Primary colors are defined in CSS variables:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #6c757d;
    --accent-color: #f8b400;
    --gradient-start: #667eea;
    --gradient-end: #764ba2;
}
```

### **Typography**
Uses Inter font family for modern, clean typography.

### **Animations**
Custom animations defined in CSS:
- `fade-up`: Fade in with upward movement
- `fade-left`: Fade in with left movement
- `fade-right`: Fade in with right movement
- `scale-up`: Scale up animation
- `bounce-in`: Bounce in effect
